# 什麼是 AI Agent

## 定義
- AI Agent 是能**代替使用者獨立完成任務**的系統。它用 LLM 管理工作流程並做決策，能判斷任務是否完成、必要時自我修正，失敗時把控制權交還給使用者。[src-05]
- 單輪的聊天機器人或單次 LLM 呼叫不算 agent。[src-05]
- Anthropic 的說法：agent 是 **LLM 自己決定步驟與工具使用**、並掌控任務如何完成的系統。[src-01]

## 白話理解
一般聊天機器人是「你問、它答」；agent 是「你交代目標，它自己想辦法、用工具、一步步做完」。
