# Agent 迴圈如何運作

## 單一 agent 迴圈
一個模型，配上工具與指示，**反覆執行直到達到結束條件**。OpenAI 建議以此作為起點。[src-05]

結束條件包含：[src-05]
- 沒有更多工具呼叫
- 產出了定義好的最終輸出
- 發生錯誤
- 達到回合上限

## 一圈在做什麼（概念化）
1. 模型根據目前資訊決定下一步
2. 呼叫工具取得資訊或執行動作
3. 把結果放回上下文
4. 判斷是否完成；沒完成就回到 1

此流程的推理與行動交錯方式，見 [react.md](react.md)。

## 為什麼需要結束條件
Agent 會自己決定步驟，若沒有回合上限或錯誤處理，可能無限進行；失敗時應把控制權交還給使用者。[src-05]

## 常見困難
遇到意外錯誤時，agent 不容易調整計畫；自然語言介面脆弱，可能出現格式錯誤。[src-04]
